# Vue 3 企业级 WBS 工作分解结构管理系统 Demo

本项目是一个基于 **Vue 3 (Composition API) + Vite** 实现的高性能、现代化企业级 **WBS (Work Breakdown Structure) 工作分解结构** 管理展示系统。包含逼真且数据量充沛（60+ 项真实业务分解任务、3级深度、8个核心里程碑）的演示工程。

---

## 🌟 核心特性与功能亮点

1. **超丰富真实业务模拟数据**：
   - 模拟大型工程项目：“新一代全渠道数智供应链与全景商业协同云平台 (Project Synergy 3.0)”
   - 涵盖 6 大一级主阶段（1.0 商业需求、2.0 架构设计、3.0 微服务研发、4.0 前端多端、5.0 质量测试与压测、6.0 割接上线）
   - 20 个二级子模块与 60+ 项细分子任务及 8 大核心战略里程碑。

2. **专业 WBS 树形表格引擎 (Tree Table)**：
   - **分级缩进与折叠**：支持逐级折叠、全部展开、全部收起，支持一键切换至“1级主阶段”、“2级子模块”、“3级工作包”。
   - **智能父子联动聚合**：子任务的工期自动对父任务进度进行**工期加权平均计算**，子任务状态变化时自动更新父级状态与预算汇总。
   - **醒目的 WBS 编码**：如 `1.0`、`1.2`、`1.2.1` 等，带有层级高亮标识。

3. **双视图无缝切换**：
   - **WBS 结构化表格视图**：详细展示编码、任务名称、交付物、层级、状态药丸、自适应进度条、责任人头像、工期日程、优先级、预算与实际成本、操作列。
   - **进度甘特/时间线微缩视图**：清晰按月份标尺渲染任务起止排期，已完成比例覆层以及战略里程碑菱形标记。

4. **实时搜索与智能展开链路**：
   - 支持根据任务名称、WBS编码、责任人、部门、交付物成果物进行实时模糊匹配。
   - 当深层子任务命中时，自动展开其**整条祖先节点链路**并进行关键词高亮，保障上下文清晰完整。

5. **多维条件组合过滤**：
   - 按状态过滤（全部 / 已完成 / 进行中 / 已延期 / 未开始）。
   - 按优先级过滤（紧急且关键 / 高 / 普通 / 低）。
   - 一键开启“仅看里程碑 (Milestone)”。

6. **项目健康度 KPI 仪表盘**：
   - 顶部提供综合完成度环形仪表盘。
   - 统计任务总数（完成/进行中/延期对比）、战略里程碑达成率、预算支出与利用率、计划总人天。

7. **任务管理与数据导出**：
   - 支持新增一级主阶段、在任意节点下添加子任务、编辑任务所有属性。
   - 支持删除任务（级联确认）。
   - 支持一键导出 **CSV (Excel 兼容，带 BOM 防乱码)** 与结构化 **JSON** 数据。

## 🚀 本地运行方式

当前 Vite 开发服务器已在本地运行，可以直接在浏览器中访问：
```bash
http://localhost:5173/
```

如需手动启动：
```bash
# 启动开发服务器
pnpm run dev
# 或 npm run dev

# 构建生产产物
pnpm run build
```
